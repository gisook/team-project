# Godot에서 맵과 기능 위치 편집하기

맵 장면 안의 기능 표시점을 게임이 읽습니다. 가구와 표시점을 함께 옮겨 저장하면 이동·상호작용·손님 경로가 새 위치를 따릅니다. 기능 연결 코드에 좌표를 입력할 필요가 없습니다.

## 현재 맵 편집

1. Godot의 파일 시스템에서 방은 `scenes/field/myroom.tscn`, 편의점은 `scenes/field/test1.tscn`을 엽니다.
2. 바닥·벽은 `FloorLayer`, 가구는 `FurnitureLayer`에서 편집합니다.
3. 장면 트리의 **Gameplay**를 펼칩니다. 표시점을 선택하면 인스펙터에서 `Role`, `Customer Id`, `Footprint` 등을 볼 수 있습니다.
4. 움직이는 가구의 타일과 해당 표시점을 함께 옮깁니다. 바닥은 현재 16픽셀 타일이므로 스냅을 켜면 배치하기 편합니다. 일반 등장·목적지 표시점은 걸을 수 있는 타일 중앙에 놓으세요.
5. 저장한 뒤 `scenes/room.tscn`을 F6으로 실행하거나 F5로 전체 게임을 다시 실행합니다. 이미 실행 중인 게임은 정지 후 다시 실행해야 새 배치를 읽습니다.

## 방의 표시점

| 기본 노드 이름 | Role | 쓰임새 |
|---|---|---|
| PlayerSpawn | `player_spawn` | 로그인·귀가·다음 날 아침에 플레이어가 서는 위치 |
| Bed | `bed` | 침대의 왼쪽 위 칸. `Footprint`가 상호작용·충돌 범위를 지정하며 밤에 E로 취침 |
| Bed/SleepPoint | 일반 Marker2D | 누웠을 때 몸이 놓이는 위치. Bed의 자식이라 침대 표시점을 옮기면 함께 이동 |
| Phone | `phone` | 휴대폰이 있는 칸. 오전·오후에 근처에서 E로 일정 선택 |
| Window | `window` | 시간대에 따라 해·달이 표시되는 창문 위치 |
| ViewBounds | `view_bounds` | 표시점이 왼쪽 위, Footprint가 화면에 담을 맵의 타일 너비·높이 |

Phone의 기본 그림은 `Visual Offset`만큼 이동해 표시됩니다. 현재는 책상 아래쪽 칸을 기능 위치로 두고 그림을 책상 위로 12픽셀 올렸습니다. 휴대폰을 다른 물체 위에 올릴 때 이 값을 조절할 수 있습니다.

SleepPoint를 생략하면 침대 Footprint의 가운데에 눕습니다. ViewBounds를 생략하면 걸을 수 있는 바닥의 범위를 기준으로 화면 크기를 자동 계산합니다.

## 편의점의 표시점

| 기본 노드 이름 | Role | Customer Id | 쓰임새 |
|---|---|---|---|
| PlayerSpawn | `player_spawn` | 빈 값 | 출근할 때 플레이어 등장 위치 |
| Cashier | `cashier` | `counter` | 계산원 자리. `Interaction Distance=0`이면 이 칸에서만 계산대 손님 응대 |
| CounterTarget | `npc_target` | `counter` | 계산대 손님이 도착해서 기다리는 칸 |
| ShelfTarget | `npc_target` | `shelf` | 진열대 손님이 도착하는 칸 |
| FridgeTarget | `npc_target` | `fridge` | 냉장고 손님이 도착하는 칸 |
| CounterSpawn | `npc_spawn` | `counter` | 계산대 손님 등장 위치 |
| ShelfSpawn | `npc_spawn` | `shelf` | 진열대 손님 등장 위치 |
| FridgeSpawn | `npc_spawn` | `fridge` | 냉장고 손님 등장 위치 |
| DrinkFridge | `fridge` | 빈 값 | 냉장고 그림과 Footprint에 따른 충돌 범위 |
| CounterPassage | `passage` | 빈 값 | 실행 중 가구 타일을 열어 두는 출입구. Footprint 범위만큼 적용 |
| ViewBounds | `view_bounds` | 빈 값 | 화면에 담을 맵 범위 |

등장 위치와 목적지는 가구 위가 아닌 바닥에 놓습니다. **냉장고를 옮길 때는 DrinkFridge와 FridgeTarget을 함께 옮기세요.** 계산대를 옮길 때는 계산대 타일·CounterTarget·Cashier·CounterPassage를 함께 조정합니다. 출입구가 필요 없는 맵은 Passage를 삭제해도 됩니다.

현재 손님은 `counter`, `shelf`, `fridge` 세 명입니다. 각 ID마다 `npc_spawn`과 `npc_target`이 한 개씩 필요합니다. ID는 대화와 연결되므로 그대로 유지하고, 노드 이름은 자유롭게 바꿔도 됩니다.

## 새 표시점 추가

기존 표시점을 복제한 다음 `Role`과 `Customer Id`를 바꾸는 방법이 가장 간단합니다. 또는 Marker2D를 추가하고 `scripts/gameplay_marker.gd`를 연결합니다. 표시점은 Gameplay 밖이나 다른 Node2D의 자식으로 배치해도 자동으로 찾습니다.

- **Footprint**: 표시점이 있는 칸에서 오른쪽·아래로 차지하는 타일 수. 침대·냉장고는 물체의 크기에 맞춥니다.
- **Blocks Movement**: 켜면 Footprint 영역이 이동을 막습니다. Sprite2D로 만든 가구에도 사용할 수 있습니다. 기존 FurnitureLayer 타일은 이 옵션과 별도로 이동을 막습니다.
- **Interaction Distance**: 물체 범위에서 몇 칸 이내까지 E 상호작용을 허용할지 정합니다. 가구와 진열대·냉장고 손님은 보통 1칸, 계산원 자리는 0칸입니다.
- **Render Visual**: 휴대폰·창문·냉장고의 기본 그림을 표시합니다. 별도 Sprite2D로 그림을 배치했다면 끄고 기능 표시점만 사용할 수 있습니다.
- **Visual Offset / Visual Size**: 기본 그림의 위치 보정, 냉장고 그림의 크기입니다. 충돌 크기는 Footprint로 따로 지정합니다.
- **Cell Size**: 편집기에서 범위를 그리는 기준 타일 크기입니다. 현재 맵은 16입니다.

필수 표시점은 Role과 Customer Id 조합이 중복되지 않게 배치하세요. Passage는 여러 개 배치할 수 있습니다.

## 다른 맵 파일로 교체

프로젝트 설정에서 고급 설정을 켜고 다음 항목에 새 `.tscn` 경로를 입력합니다. 또는 `project.godot`의 `[gameplay]`에서 수정합니다.

```ini
[gameplay]
maps/room="res://scenes/field/myroom.tscn"
maps/store="res://scenes/field/test1.tscn"
```

새 맵은 기존 맵을 복제해 만드는 것을 권장합니다. Node2D 루트 아래에 `FloorLayer`, `FurnitureLayer` 두 TileMapLayer와 `Maincharacter` 캐릭터를 유지하고 필수 표시점을 배치하세요. Camera2D는 선택 사항입니다. 내보내기에서 선택한 장면만 포함하는 경우에는 새 맵과 사용하는 리소스도 포함해야 합니다.

벽은 FloorLayer의 TileSet 충돌 정보로, 가구는 FurnitureLayer의 배치와 표시점의 Blocks Movement로 판단합니다. 맵 크기와 원점이 바뀌어도 타일 좌표로 계산하므로 코드 좌표를 변경할 필요가 없습니다.

## 배치 오류 확인

게임을 시작할 때 필수 표시점, 중복 ID, 가구 위 등장·목적지, 길이 막힌 손님과 접근할 수 없는 상호작용 위치를 검사합니다. 문제가 있으면 이동과 진행을 멈추고 화면 위에 표시점 역할이나 이름을 안내합니다. 해당 배치를 수정하고 게임을 다시 실행하세요.
