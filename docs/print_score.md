# 결과 출력 씬 추가

`feature/npc-interaction`의 prototype을 기준으로 만든 `print_score` 브랜치입니다.

## 변경 내용

- `scenes/field/print_score.tscn`: 파일별 발음 평가 결과 화면.
- `scenes/field/print_score.gd`: 서버의 `accuracy_score`, `fluency_score`, `completeness_score`, `pron_score`를 정확도·유창성·완전성·종합으로 표시합니다.
- `scenes/field/test_1.gd`: 모든 서버 요청이 완료되면 수집한 결과를 넘기고 결과 화면으로 이동합니다.

## 테스트 위치와 방법

1. GitHub Desktop에서 `print_score` 브랜치를 선택합니다.
2. 이 프로젝트의 `project.godot`을 Godot 4.7에서 엽니다.
3. 발음 평가 서버를 `http://127.0.0.1:8000/api/pronunciation/assess`에서 실행합니다. 서버가 다른 주소에 있다면 `scenes/field/test_1.gd`의 `SERVER_URL`을 해당 주소로 변경합니다.
4. `scenes/field/test1.tscn`을 열고 **F6(현재 씬 실행)**을 누릅니다. 로그인 화면을 거치지 않고 편의점에서 테스트할 수 있습니다.
5. NPC 근처에서 **E**를 누르고 답변을 선택합니다. **녹음 시작**을 누르고 말한 뒤, 같은 버튼을 다시 눌러 녹음을 종료·저장합니다.
6. **일정 종료**를 누릅니다. 모든 요청이 끝나면 결과 화면으로 이동하며, 성공한 파일마다 네 점수가 표시되는지 확인합니다.

녹음은 이번 실행에서 새로 해야 합니다. 폴더에 WAV 파일만 있어도 자동으로 전송 목록에 들어가지는 않습니다. 녹음 없이 일정 종료를 누르면 기존 동작대로 방으로 이동합니다.

`scenes/field/print_score.tscn`만 열어 F6으로 실행하면 화면 구성과 '표시할 평가 결과가 없습니다.' 문구를 확인할 수 있습니다. 실제 점수 확인은 위 편의점 흐름에서 진행하세요.

현재 연결 코드는 성공한 응답만 `results`에 저장합니다. 실패 응답은 기존처럼 콘솔에 출력되며, 모든 요청이 실패하면 결과 화면에 표시할 결과가 없다고 나옵니다.

## 확인한 범위

Godot 4.7.2에서 결과 씬 로딩, 네 점수 매핑, 0점·소수점·누락 값·빈 결과 표시를 확인했습니다. 결과 씬에 실패 항목을 직접 전달했을 때의 표시도 확인했습니다. 실제 서버와 마이크를 사용하는 전체 흐름은 별도 테스트가 필요합니다.
